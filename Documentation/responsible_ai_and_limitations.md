# Responsible AI and limitations
**Grounding.** Context-only prompt, mandatory `[S#]` page-tagged citations, post-hoc citation validation, evidence always visible, refusal gate (LLM not called) when similarity is low.
**Transparency.** The answer mode is displayed on every answer; fallbacks are never labelled as LLM output.
**Privacy.** Documents, chunks and embeddings stay on your PC. Ollama keeps generation local. A hosted endpoint receives the retrieved passages and your question - use only synthetic or public documents there. API keys: environment variables or session-only field; never saved to config, logs or the ZIP.
**Security.** PDF-only upload; invalid/encrypted files rejected; retrieved text treated as untrusted data (prompt-injection rule is a mitigation, not a guarantee); no document content is executed.
**Human oversight.** LLM answers must be verified against the evidence; extracted items are candidates with a review column; nothing is approved automatically; not AUTOSAR compliance verification.
**Limitations.** Small CPU LLMs can hallucinate, mis-cite or ignore the refusal rule; `dense_min_score` is untuned; MiniLM is a general English model (domain terms like SWC/port names may embed poorly); tables/diagrams are not interpreted; chunking is sentence-based; FAISS optional; no RBAC/audit log/DB; first run needs internet for the model download; real-environment (Windows 11 / Python 3.13) behaviour not verified by the author; synthetic benchmarks do not prove real-world accuracy; the official AUTOSAR PDF is a public reference document, not a project HLD.
